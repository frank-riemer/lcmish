# README image assets

Images in this directory support the project README.

- `lcmish-fit-report-preview.png` is a rendered preview of the synthetic example report in `examples/LCMish_synthetic_fit_summary.pdf`.
- `in-vivo-four-fitter-comparison.png` is an illustrative comparison using the same deidentified in-vivo 31P spectrum for all four panels. Display scaling is applied independently, and differences in basis sets, priors, baseline models, preprocessing, and optimisation mean that the figure is not a quantitative equivalence test.

No identifiable source data are included in these image files.
