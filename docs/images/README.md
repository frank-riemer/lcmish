# README image assets

Images in this directory support the project README.

- `lcmish-fit-report-preview.png` previews the report layout in `examples/LCMish_synthetic_fit_summary.pdf`.
- `lcmish-in-vivo-example.png` shows a whole-spectrum fit and residual for a deidentified, phase-corrected eight-voxel mean in-vivo 31P spectrum.

No identifiable source data are included in these image files.
