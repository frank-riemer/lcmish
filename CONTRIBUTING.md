# Contributing

Contributions are welcome, particularly when they arrive with a test and without a mysterious hard-coded path to somebody's external drive.

Please:

1. open an issue for substantial behavioural changes;
2. keep scientific assumptions explicit in code and documentation;
3. add or update tests for numerical changes;
4. avoid committing patient data, proprietary basis sets or scanner exports whose redistribution status is unclear;
5. report comparisons against established spectroscopy software with enough acquisition and fitting detail to reproduce them.

For numerical changes, a plot that looks nicer is encouraging but not, by itself, a validation strategy.
